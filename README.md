# 番茄轻语 v1

根据 `PRD.md` 实现的静态网页 MVP。

## 运行

剧情内容通过 `public/data/stories.json` 加载，请在项目目录启动静态服务：

```bash
python3 -m http.server 5173
```

访问 `http://localhost:5173`。

## v1 范围

- 本轮任务输入，最多 15 字，可为空
- 番茄时长自定义，最低 25 分钟
- 开始、暂停、继续、退出、休息、跳过休息
- 使用真实时间戳计算剩余时间，刷新页面可恢复
- 单角色「岁岁」与 5 段固定剧情
- 完成番茄后推进剧情并写入画廊
- 开始下一轮前处理未完成剧情选项
- localStorage 保存进度、设置、画廊和任务历史
- 静音模式、音乐选择、音量设置
